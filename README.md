

# Dotfiles
This is my personal collection of dotfiles used to customize my Linux setup — mainly focused on Hyprland and related applications.

## Installation
This setup is intended for Arch Linux or Arch-based distributions.

### Clone the Repo
```bash
git clone git@github.com:USERNAME/.dotfiles.git ~/.dotfiles
```
Run the Installer
```bash
cd ~/.dotfiles
./install.sh
```

Follow the instructions shown in the terminal.
